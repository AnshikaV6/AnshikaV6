## 🔍 How LostLink Works

````mermaid
flowchart LR
    A[Report lost item] --> C{Matching engine}
    B[Report found item] --> C
    C --> D[Compare category, name, colour, description, location, date]
    D --> E[Score from 0 to 100]
    E --> F[High potential match]
    E --> G[Possible match]
    E --> H[Low similarity]
````

> [!NOTE]
> The score shows similarity only. It is not proof of ownership.
